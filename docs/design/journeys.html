03 · Customize

Settings, applied live

Menu bar → Settings (⌘,). Toolbar tabs; changes apply immediately, including the theme on the open window.

⌨ Keyboard

Record the shortcut, release behavior, bare Tab (with a clear warning).

🖌 Appearance

Theme, layout, icon size, appearance as picture pickers; visible rows; display; centered or draggable; search field.

⚙ Behavior

Launch at login, outside click, window order (Smart / Recent / Name), windows to include, VS Code, updates.

🛡 Permissions

Accessibility status and fixes; Input Monitoring and Screen Recording shown as "not needed".

🔧 Advanced

Debug logging, refresh, reset recents, diagnostics report, Quit.

06 · Recovery

When Accessibility goes missing

macOS updates or a reinstall can drop the grant. Swoop says so plainly and gets you back in two clicks.

→

→

→
